# Airbnb AI Price Prediction Platform

An AI-powered web application that helps users predict Airbnb listing prices and analyze market trends using Machine Learning, Flask, and interactive dashboards.

---

## Features

- AI-based Airbnb price prediction
- Interactive dashboard with charts and filters
- Map-based location insights
- User authentication (Login/Register)
- User profile management
- Booking functionality
- Modern landing page UI

---

## Tech Stack

**Frontend:**  
- HTML  
- CSS  
- Bootstrap  

**Backend:**  
- Flask  
- SQLite  

**Machine Learning:**  
- Scikit-learn  
- Pandas  
- NumPy  

**Visualization:**  
- Plotly  

---

## Project Workflow

1. User registers/logs in  
2. Enters Airbnb listing details  
3. ML model predicts price  
4. Dashboard provides market insights  
5. Users manage profile and bookings
